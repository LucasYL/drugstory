# v0.11 终局评级、阶段目标、角色专长与最后的难题 · 试玩记录

2026-11-08。起因：用户试玩 v0.10 后反馈：
- 完整性够了，但不够好玩、上手门槛高；
- 没有激励和完结机制，不知道怎么评判经营质量；
- 年度评奖不是每年都有药可报，而且容易忘记报名；
- 不需要任何传奇也能达到最好效果；
- 阿尔茨海默怎么都做不出来。

讨论稿和人物原型见 [v11-proposal.md](v11-proposal.md) 与 `design/v11/characters.html`。用户确认方向后，提出三点修改：传奇改成学术专家形象，人种更多样（仍以亚洲人为主），新增高上限角色李天天、给唐小柚换名。

本版改了规则，存档格式升到 v9。开发、模拟、鼠标试玩全部在这个分支的独立 checkout、独立端口（8911–8916）和从新局生成的独立存档（`.artifacts/qa11`、`.artifacts/v11-study`）上进行，没有读写、推进或替换玩家存档。v0.10（`03e0eda`）在 8886 端口同时运行正常。

## 一、先量：v0.10 的问题出在哪

`scripts/boundary-hard-targets.py`，构造的后期状态（不是正常经营），五个专业各一人，只用公开证据的模拟玩家，β-淀粉样蛋白 × 单抗，种子 1–40：

| 团队（v0.10 规则） | 能力 | 获批 |
|---|---|---:|
| 五位传奇 | 97 | 30/40 |
| 五位见习练到传奇 | 97 | 30/40（逐局相同） |
| 五位见习练到大师 | 77–80 | 23/40 |
| 同上，直接选候选、不做专项研究 | 77–80 | 2/40 |

结论：传奇和自家练成的传奇没有区别；人是谁几乎不影响结果；真正的分水岭是「按证据挑候选、对获益做定向优化」，而游戏从没告诉玩家。「没有能结合的口袋」的小分子组合仍有 9/40 获批。

更正讨论稿的一处说法：讨论稿写「单抗和 ASO 逐局结果完全一样」。这是因为测试里两个组合都用同一个项目编号，候选随机数的键相同，正常经营里不会这样。本版还是把药物类型加进了候选抽取的随机键。

## 二、改了什么

1. **年度评选自动参评。**
   - 取消报名，年末自动评所有类别；每年最多一个大奖，其余胜出的类别记为提名。
   - 合作奖改为研发进展奖：本年通过的阶段按阶段计分，合作项目也算，没有新药的年份也能争。
   - 对手领先线每年提高 2.5 分；同类第二次获奖奖金减半。
2. **研究顾问。**
   - 创新药临床前，获益离后期门槛不到 9 分时，提示先做定向优化，给出按公开证据估算的前后机会，并带一键安排按钮。
   - 有条件时提示人群分层；临床阶段后续机会低于 15% 时提示授权或止损。
   - 一键方案先说成功机会高、中、低，再给区间。
3. **任期与研究所评级。**
   - 开局选十年或二十年任期，任期结束那周评级定格，之后可以继续经营；停业时提前结算。
   - 五项评分：惠及患者 30%、科学突破 25%、团队传承 20%、经营稳健 15%、行业声誉 10%，评 S 到 D。
   - 结局看哪一项比一般水平更突出；不到 B 用朴素的结局。
   - 顶栏常驻「预计评级」。
4. **角色。**
   - 每人一项改变规则的专长：工期、读数噪声、门槛、筛选信息、失败补救、回款和毛利。大师后完成个人课题即觉醒。
   - 潜力上限：见习 88、精英 91、大师 94、传奇 97，李天天 99。
   - 传奇在职满八年退休（提前一年提醒，手上有活就等做完），退休前可以把专长传给同专业弟子一次。
   - 李天天第二年起收到「少年班来信」后可以邀请：经验 ×1.5；觉醒后可以跨专业继承两位传奇本人的专长。
   - 唐小柚改名娜迪亚·拉赫曼。为了多样性，另有四人换人，原有位置、外号、专长不变：
     - 顾远航 → 丹尼尔·奥孔
     - 周默 → 奥马尔·哈达德
     - 钟砚秋 → 伊莲娜·沃尔科娃
     - 陆观潮 → 伊莎贝尔·罗哈斯
5. **阿尔茨海默四道关。**
   - 入脑、选对人、脑水肿、长终点；缺了抬高门槛、加大 III 期噪声或拉长工期。
   - 每关有完全解决和部分解决的人选，疾病卡上直接列出谁能过。
   - 不可能的组合（适配 −2）获益压在 II 期门槛以下。
6. **章节、疾病地图、患者委托。**
   - 五章目标，按可选目标给一到三星和奖励，不锁住玩家。
   - 疾病地图分常见病、新药、难治、最后的难题四层，攻克后亮起，附一句患者的话。
   - 第三年起约每两年一封患者组织来信，委托限期让某种疾病有药，过期不罚。
7. **新画法。**
   - 第二稿画风接入场景、头像、图鉴：专业色就是衣服颜色，每人一个大剪影。
   - 传奇是戴月桂徽章的学术专家；人物长相更多样。
   - 页面安全策略只额外放开 `data:` 图片。

## 三、阿尔茨海默：现在的配方

同一个边界测试，v0.11 规则，种子 1–40（构造状态，与正常经营分开说明）。

「分层打法」指照研究顾问的提示：先做人群分层研究，II 期起分层入组。现有的证据型模拟玩家不会这样做，测试里另写了一个只读公开信息的玩家。

| 团队 | 单抗 | ASO |
|---|---:|---:|
| 五位传奇（没有傅以宁） | 0/40 | 10/40 |
| 五位见习练到大师（没有关卡人物） | 0/40 | 3/40 |
| 四道关全靠大师（傅以宁觉醒、沈墨言、白若霜、欧阳岚） | 14/40 | 8/40 |
| 四道关完全解决（傅以宁觉醒、沈墨言、孟长青、伊莎贝尔） | 16/40 | 9/40 |
| 全靠大师 + 分层打法 | 24/40 | 14/40 |
| 完全解决 + 分层打法 | 30/40 | 19/40 |

读法：
- 单抗必须有觉醒的傅以宁（脑穿梭递送），否则谁来都几乎做不出。
- 选对人这一关要沈墨言加上分层入组。
- 传奇（孟长青、伊莎贝尔）再加大约 15 个百分点。
- 不靠传奇也有路：只靠大师、按顾问的打法，约六成。

和讨论稿目标的差别：讨论稿目标是「全靠部分解决约 25–30%」「全部完全解决约 60–65%」。实际只靠大师更容易（35% 不分层、60% 分层），完全解决略高于目标（75%）。原因是大师们都有对应专长，而「脑水肿」「长终点」两关的部分解决在安全余量充足时影响不大。暂时保留，等真人试玩反馈再调。

## 四、正常经营的模拟

`scripts/playtest-v11.py`，种子 1–12，每局 960 周（20 年），共 96 局。三种玩家都只读公开信息，不读候选真值，不注资：
- **默认玩家**：只点界面推荐按钮。
- **证据玩家**：按证据挑候选，必要时定向优化，期中估计太低就止损。
- **新手玩家**：直接选中间候选，不做专项研究。

| 玩家 | 停业 | 评级 | 平均总分 | 完成章节 | 大奖 / 提名（每局） | 上市 仿制 / 改良 / 创新（难治） | 惠及患者中位数 |
|---|---:|---|---:|---:|---|---|---:|
| 默认·谨慎·标准 | 0 | B 9 · C 3 | 54.9 | 2.0 | 4.5 / 1.5 | 11.2 / 5.5 / 0 | 436 万 |
| 默认·大胆·标准 | 1 | A 5 · B 6 · D 1 | 62.3 | 3.4 | 6.8 / 2.4 | 5.2 / 2.6 / 4.2（1.2） | 376 万 |
| 默认·谨慎·竞逐 | 0 | B 4 · C 8 | 52.9 | 2.0 | 2.7 / 0.3 | 11.2 / 5.6 / 0 | 404 万 |
| 默认·大胆·竞逐 | 1 | A 2 · B 9 · D 1 | 58.8 | 3.2 | 3.9 / 0.8 | 5.2 / 2.5 / 3.9（1.0） | 354 万 |
| 证据·起步药坊 | 0 | A 8 · B 4 | 71.2 | 3.8 | 5.9 / 2.1 | 10.3 / 3.5 / 3.2（1.0） | 462 万 |
| 证据·创新研究社 | 0 | A 7 · B 5 | 70.6 | 3.7 | 5.2 / 2.5 | 11.8 / 3.2 / 3.0（0.9） | 501 万 |

评级（目标：新手 C，好打法 B 到 A，S 留给攻克难题或极致）：
- 新手多为 C，默认玩家多为 B，证据玩家多为 A。
- 96 局没有 S，也没有一局做出阿尔茨海默。

结局随打法变化：
- 谨慎派多是「普惠药业」或「街坊药房」；
- 大胆派和证据玩家多是「星火生命科学大奖」；
- 新手多是「师徒工作室」或「薪火研究院」。

年度奖：v0.10 证据型模拟每局 7–13 个，现在 3–8 个，平均 4–7 个，落在目标内；竞逐模式更难拿。

章节：谨慎派停在第 3 章（不做创新药）；大胆派和证据玩家平均完成 3.2–3.8 章；第 5 章无人完成。

角色：
- 证据玩家平均每局有 2.1 位传奇退休；默认玩家几乎每局都请了李天天（23/24）。
- 自动玩家都不会安排传承（0 次）。

委托：三种玩家都不会针对委托选药，完成率 0–5%。这说明不了真人玩家的完成率。

### 停业的那一局

默认·大胆在第 5 号种子上，两种难度都在第 128 周停业。v0.10 同一局没有停业，但最低现金只剩 426 万。

这个玩家开局就直接押创新药，同一时间还在做仿制药。陈一鸣的「通宵冲刺」把候选优化提前了 4 周，于是 III 期的大笔支出和仿制药上市前的空档叠在一起。III 期做完后，审评被已承诺支出卡住只能暂缓，三个月现金为负，停业。

关掉陈一鸣的冲刺，同一局不会停业（最低现金 161 万）。这是开局只有 2600 万还直接押创新药的打法本来就悬，不是专长出错。本版没有为这一局改数值。顶栏现金提示、开工前的现金提醒、现金转负自动暂停都还在。

## 五、v0.8 策略回归

七种 v0.8 策略 × 两种难度 × 种子 1–2，共 28 局，在新规则下全部跑完、无停业。规则变了，所以结果不再和 v0.8 记录逐项相同，这是预期的。

## 七、已知限制

- 自动玩家不会安排传承、不会针对患者委托选药，也不会主动分层入组。这三块的平衡要靠真人试玩。
- 正常经营的 96 局里没有一局做出阿尔茨海默，也没有 S 评级。S 现在主要靠攻克最后的难题，需要真人试玩看是否太难。
- 场景小人改为静态图，只保留走路摇摆和上下起伏，旧画法的抬手、喝茶等小动作暂时没有了。图片加载前会短暂显示旧画法。
- 讨论稿里的「自有工厂」后期支出目标没有做，高铁峰的专长暂时是毛利 +6%。
- 默认·大胆在一个种子上停业，见第四节。
- 版本 tag 和 GitHub Release 需要在本地完成：这个云端会话推不了 tag。
- 自动策略的评级和胜率不是人类玩家的，也不说明游戏一定好玩。
