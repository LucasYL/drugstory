## 1. 本轮做了什么

### 个人课题与协作

20 位角色各有一个专业相关的题目、一段动机和指定搭档专业。经营满 48 周、能力 40，且完成一个项目或参与三次研究阶段后解锁。课题占用本人及一位伙伴：

- 交叉复现：12 周、140 万。与对应专业伙伴在同一阶段工作，相关指标观察误差减少 8%；临床角色作用于临床阶段观察。
- 联合交接：8 周、80 万。同样需要伙伴配合，相关阶段费用减少 5%。

完成后永久保留一种能力，不能反复付费叠加或重新选择。课题抵一项晋阶履历要求，但不会伪造已完成项目。相同类别协作加成不按人数无限叠加；更强角色不能仅靠能力值代替指定专业。当前是 20 个小目标加两种通用研究方法，尚不是 20 套独立剧情分支和技能树。

### 临床中途决策与少点几次

I、II、III 期及改良药桥接/确认阶段，各在过半时停一次；普通仿制的等效性不额外插入中途弹窗。选择发生在最终疗效结果揭晓前：维持方案、补充监测、补齐代表性中心、限制后续中心网络、独立核查、远程随访等。

增加随访只改变精度，不直接改善候选性质。限制中心网络缩短 3 周，但上市覆盖减少 15%，III 期继续沿用；不是看过疗效后随意挑选获益亚组。额外成本即时扣除，调整时间保持尚未支出的原阶段预算不变。暂缓决策时人员和承诺预算继续占用，阶段计时与研发收费暂停，工资照常。

「安排下一阶段」合并准备与安排团队；预览使用下一阶段而非刚完成的阶段。可一次提交 1–3 项服务安排，任何一项冲突时整批不生效。

### 可选产业竞逐

开局选定，不能中途切换难度。标准模式不增加平台维护或领域总容量限制。挑战模式对手工期约缩短 15%、阶段成功率提高 4 个百分点（最高 96%）、商业影响增强 25%，年度对手成绩基线加 6。对手仍会失败、延迟和调整方向。

每周领域总容量为：高血压 90、血脂 190、疼痛 110、糖代谢 95、过敏 85、炎症 210、肺癌 250 万。分配按同领域产品与对手的简化需求计算，范围 0–100%；这不是完整价格竞争或玩家与对手的资产负债表模型。

四级场地的基础平台维护费为 0 / 5 / 16 / 36 万每周，按选择乘系数：节约 0.65（误差 +8%），常规 1（阶段费 −3%），精密 1.65（误差 −8%、阶段费 −5%）。作用于本公司负责的研究安排，包括委托执行中的研究管理；不改变合作方独立开发。扩建前显示新场地维护费，现金周预测包括维护，不与累计财富挂钩。审批门槛不因挑战模式、年份或财富提高。

### 9 个产品特性

供货韧性、低剂量均匀性、溶出一致性、储存稳定、小片易服、杂质控制、长效依从性、耐受改善、便携给药，各有相关阶段和指标约束。立项时选择标准或强化验证；强化在关键阶段增加 25% 费用、2 周时间，观察误差减少 20%。通过后才获得对应产品效果：免除周期供货折减、利润率增加 3 个百分点、生命周期延长 48 周、导入加快及需求提高等。

这些是同一研发框架中的不同约束与商业价值，仍使用现有四类证据。复杂仿制、生物类似药尚未加入，不把它们简单换名作为新增玩法。

## 2. 模拟方法

两轮各 72 局，共 144 次自动经营。每轮：六种策略 × 两种模式 × 种子 1–6；最多 960 周（20 年），破产提前停止。第一轮为功能集成检查，最终轮修正过期产品当周份额后复测；两轮不合并成胜率，表中仅使用最终 72 局。

```bash
uv run python scripts/playtest-v06.py --seeds 6 --output .artifacts/v06-first
uv run python scripts/playtest-v06.py --seeds 6 --output .artifacts/v06-final
uv run python scripts/prepare-v06-playtests.py
```

策略继承 v0.5 的公开证据调度，新增：资金充足时开展个人课题；稳健/培养/科研补监测与随访，冒险路线尝试缩小中心和远程随访；仿制/培养/稳健尝试强化产品验证；挑战模式按资金余量调整维护。它们有共同基础算法，不是六个独立人类玩家。不注入金钱、能力或候选质量，不读取隐藏性质；单元测试中的强候选夹具另行标注。

每轮保存各策略/模式前两个种子的完整操作记录；所有结果汇总在本地 `.artifacts/v06-final/results.json`。原始存档不上传 GitHub。源代码与本记录支持复现，玩家存档从未用于模拟。

### 如何解读

1. 个人课题进入中期，能占用有价值的研究时间并留下永久配合能力。角色内容从单纯等待经验前进了一步，但目前课题互动仍短，不能称为完整剧情养成。
2. 临床中途现在有可解释的选择，仍保留零额外成本路径。增加精度不一定提高通过率：候选本来较差时，更准确的研究可能更明确地失败。
3. 挑战模式降低稳健/仿制路线的期末现金，培养路线过度扩张会更吃紧；授权路线仍明显富裕。它目前是扩张与维护挑战，不是所有路线都同难度的硬核模式。
4. 部分挑战策略反而获得更多创新药或大奖。成本改变了何时开项目、招聘和研究，同种子后续路径发生变化；不能将这 6 对样本视为“挑战必然更难/更容易”的可靠概率结论。
5. 普通开局第一款仿制中位数约 41–52 周；重培训策略约 138 周。培训仍不能替代真实项目经验，教学应提示先建立现金流，再长期脱产培养。
6. 后期现金积累仍多，产品约束也仍有数值共性。下一轮优先观察真人是否真正使用人物搭档、是否总点同一种临床选择，再决定增加专属解法；不再直接抬审批门槛来消耗财富。

开发中修复：临床专业的复现能力最初没有对应指标、临床变更后的概率缓存未更新、下一阶段预览需指向新阶段、过期产品在退出当周影响同领域份额、错误项目预览抛出未处理异常、小窗口样稿场景被挤出首屏。这些问题修正后重新验证。

最终 **269 项测试通过**，包含新课题占用与不可重复、专业协作与候选性质不变、临床检查点暂停/预算/重载/一次性选择、商业覆盖继承、下一阶段原子提交、批量订单失败回滚、固定维护费与现金预测、容量上限和不变审批、特性奖励需通过、v6 回放与旧存档拒绝。Ruff、三份真实 UI JS 与样稿 JS 语法、diff 检查通过。
