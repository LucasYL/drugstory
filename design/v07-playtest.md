# v0.7 试玩与验证记录

日期：2026-11-04。所有自动经营使用独立新局，未读取或推进玩家存档。
## 做了什么，为什么

原模型角色收益集中在精度与速度，不能清楚表达培养价值。本轮增加有专业分工、递减成员收益和有限上限的开发工作，保留临床证据揭晓；恢复 288 组合并缩短创新标准路径。零碎角色加成合为招牌能力，移除维护/专长/生产切换，新增有限设备投资。UI 先保持文字，偏写实场景只做原型图。

## 配对团队边界实验

`uv run python scripts/benchmark-v07.py --seeds 400`。两个组合各 400 个共同种子，每个候选池只生成一次，用公开证据选预估最佳候选，再复制给各团队。角色沿用同一组普通角色身份，能力控制为 35 / 58 / 90，对应见习 / 精英 / 传奇；无限融资、全平台只是为了隔离团队作用。**不是完整经营，也不是人类胜率；不与 Claude 未独立复现的表格作严格前后比较。**

每个团队走标准方案、不额外优化、不补正，期中一律继续。团队人数条件指每位负责人下属成员，最多三个负责人同时进入阶段。完成指一路通过审评。

## 得到的判断

- 团队价值已明显恢复，成长不再只意味着误差减少；同一候选仍可能失败。普通角色靠课题和成长能持续承担工作。
- 首位传奇大致落在第 8–12 年，阶段中间有开发批次、证据和期中止损反馈。但“新产品/奖/晋阶”大事件间隔仍可能两三年，分批动画不能代替新内容。
- 两模式 84 局均未破产，说明这些成熟且保守的自动策略较稳；**不能据此称竞争模式足够难**。普通模式全部公司目标达成，竞争模式 41/42；更难的科学终局只在部分专门路线出现。
- 后期仍有数亿元余额，设备只是有限、可见的投资入口，尚未解决长期经济循环。纯仿制路线后半程的新内容仍较少。
- 288 组合增加探索宽度，但目前还复用创新流程和指标；新增四类市场的对手覆盖也不足。下一步更适合补少量有独特约束的组合与对手反应，而不是继续增加乘数。

专用 8885 / `.artifacts/v07-browser-qa.json`，未使用正式 8883 新局或玩家 8880 存档。

- seed 771：稳压片候选 3，首次 BE 第 34 周未过；选择真实工艺补正，再验证仍未过，历史失败保留。之后测试脚本继续空转至第 260 周破产，仅验证负现金保护，**不是有经营动作的完整人类路线**；新开局前备份了这份记录。
