## 1. 靶点

### 1.1 标签

| 标签 | 取值 | 含义 |
|---|---|---|
| 位置 | 胞外分泌 / 细胞表面 / 细胞内 / 基因层面 | 药要到哪里才能碰到它 |
| 口袋 | 有 / 难 / 无 | 有没有小分子能结合的口袋 |
| 干预 | 抑制 / 激活 / 清除（细胞或斑块）/ 补上缺失的功能 / 诱导免疫 | 要对它做什么才能治病 |
| 组织 | 全身 / 肝脏 / 中枢 / 实体瘤 / 血液肿瘤 / 免疫细胞 | 药要送到哪里 |

## 3. 组合规则

### 3.1 计算步骤

1. 先查特例表（3.2 节），有就直接用。
2. 以下情况直接判为"很差"：
   - 分子类型只能打细胞表面（ADC、CAR-T），而靶点不在细胞表面
   - 靶点在细胞内，分子类型进不了细胞
   - 靶点在基因层面，分子类型作用不到基因层面
   - 分子类型需要功能口袋（小分子），靶点没有口袋
   - 蛋白降解剂碰上分泌到细胞外的蛋白
3. 否则从 0 分开始加减：
   - **干预方式**：对得上 +1，对不上 −1。两个例外：
     - 双抗只有在需要清除时才 +1，单纯抑制算 0（单个靶点用不上第二条臂）
     - 降解剂只有在口袋很难做时才 +1，否则算 0（已经有好用的抑制剂了）
   - **主场 +1**：小分子遇到现成的口袋；单抗遇到细胞外、没有口袋、需要抑制的靶点；双抗清除血液肿瘤；多肽激动细胞表面的受体；mRNA 做疫苗；基因治疗补上缺失的基因
   - **口袋**：小分子遇到很难做的口袋 −1；降解剂遇到没有口袋的靶点 −1，遇到不在细胞内的靶点也 −1
   - **组织**：靶点在中枢、分子类型过不了血脑屏障 −2；否则，如果分子类型送不到靶点所在的组织 −2（做疫苗时不受限）
   - **擅长这个组织 +1**：siRNA 对肝脏；ASO 对肝脏、中枢；ADC 对实体瘤；CAR-T 对血液肿瘤
   - **CAR-T 打实体瘤 −2**
4. 结果限制在 −2 到 +2 之间：+2 绝配，+1 好，0 一般，−1 差，−2 很差。

规则算出来的每一格都附带原因，比如"siRNA 擅长抑制；很适合肝脏"，游戏里直接展示给玩家。

## 5. 结果文案

每类疾病有自己的指标。数值按分数线性换算：分数 1 对应下限，10 对应上限。

| 文案类型 | II 期指标 | III 期指标 |
|---|---|---|
| 实体瘤 | 客观缓解率 5%–70% | 死亡风险降低 0%–45% |
| 血液肿瘤 | 完全缓解率 10%–85% | 疾病进展风险降低 0%–60% |
| 代谢 | 体重下降 2%–25% | 糖化血红蛋白下降 0.3–2.5 个百分点 |
| 血脂 | 目标血脂下降 10%–85% | 心血管事件风险降低 0%–30% |
| 神经退行 | 斑块减少 5%–80% | 认知衰退减缓 0%–40% |
| 偏头痛 | 每月偏头痛天数减少 0.5–6 天 | 偏头痛天数减半的患者比例 10%–60% |
| 罕见病 | 生物标志物改善 10%–90% | 关键功能评分改善 5%–70% |
| 自身免疫 | 达标率（ACR20 / PASI 90 / EASI 75）10%–75% | 达标率 10%–75% |
| 疫苗 | 中和抗体阳转率 30%–99% | 保护率 30%–95% |
| 抗病毒 | 病毒载量下降 1–5 log | 病毒学应答率 20%–95% |

I 期按安全性和成药性出文案：

- 安全性高："未见剂量限制性毒性"；安全性低："出现〈隐患〉，需要降低剂量"
- 成药性按给药方式："半衰期 18 小时，支持每日一次口服""支持每月一次皮下注射"

例子：III 期疗效 8 分的实体瘤药，文案是"主要终点达成，死亡风险降低 34%"。

## 6. 隐患

每个隐患属于一项属性，严重度为 1 或 2。分子类型有自己专属的隐患，会和通用隐患一起抽。

| 属性 | 通用隐患 | 分子类型专属 |
|---|---|---|
| 安全性 | 肝毒性、心脏毒性（hERG）、骨髓抑制、致畸风险 | ADC：载荷脱落；CAR-T：细胞因子风暴；基因治疗：AAV 引起肝损伤；mRNA：LNP 引起炎症反应；单抗：抗药抗体 |
| 成药性 | 溶解度差、半衰期太短、口服吸收差、脱靶 | 单抗：聚集；多肽：降解太快；siRNA：内体逃逸效率低 |
| 可生产性 | 杂质超标、收率低、批次差异大、稳定性差 | CAR-T：细胞扩增失败；基因治疗：病毒载体产量低；ADC：偶联比例不稳定 |
